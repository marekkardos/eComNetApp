# Social Login Integration

Add OAuth2 social login options for Google. Simplify registration and login while maintaining security.

## Rationale
Social login reduces registration friction and abandonment. Many users prefer social login for convenience and password fatigue reduction.

## User Stories
- As a shopper, I want to log in with Google so that I don't need another password
- As a shopper, I want quick registration so that I can checkout faster
- As an existing user, I want to link my social account for easier future logins

## Acceptance Criteria
- [ ] Users can register/login with Google account
- [ ] Social accounts can be linked to existing accounts
- [ ] Social login is secure with proper OAuth2 flow
- [ ] Users can unlink social accounts
- [ ] Fallback to email/password always available
